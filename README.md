# Venera 个人漫画源

适用于兼容 Venera JavaScript 扩展的阅读器，当前目标为 VeneraNext 1.18.1。此仓库公开分发包子、拷贝和漫蛙的个人测试脚本与源清单，不提供漫画文件，不隶属于阅读器或源站运营方。

## 开发说明

本项目借助 **OpenAI Codex** 进行代码编写、问题排查、测试与文档整理，由仓库维护者提出需求并组织维护和发布。

本项目不是 OpenAI 官方项目。AI 辅助开发不代表已经消除所有错误或完成专业安全审计，发布的脚本仍需测试和审查。

**当前为预览版。** 开发测试和初步手机试用通过不代表全部作品、章节、设备或网络环境均可用。安装前请阅读 [使用与隐私说明](NOTICE.md)。

## 添加与更新

1. 在 App 打开“漫画源 → 添加来源”，粘贴上面的清单地址。
2. 点击“识别并预览”，勾选需要的源，选择“保存为来源仓库”，再安装。
3. 已经通过 JS 文件安装的同名源，可在“管理来源”中关联本仓库。关联前先确认源的 key 一致，不必先卸载源或清除数据。
4. 后续从关联仓库检查并安装更新。更新发布可能晚于源站变化，请查看仓库的改动记录。

三个源是独立脚本。这个链接提供统一安装和版本目录，不会把它们合成一个漫画站，也不会替代源站账号、权限或可用性。

## 已知限制

- 包子搜索目前只读取首个搜索页，目录和章节可按源站实际链接读取。
- 拷贝使用匿名客户端兼容协议；遇到 HTTP 210/429 直接报错，不自动轮换身份。兼容协议可能随站点变化。
- 漫蛙支持站点搜索、搜索及漫画列表翻页、详情和章节；未实现题材筛选或独立更新列表。未验证的封面线路留空，不隐藏作品。
- 站点下架、验证要求、图片失效和接口变化可能导致无法阅读，脚本不能保证恢复源站没有提供的数据。
- 本版脚本自身的单文件更新地址留空；请保存并关联源仓库，通过仓库清单更新。仅下载 JS 文件而未关联仓库时，不会获得清单版本检查。
- 同一 key 用于识别源，更新时保持不变；导入覆盖后的续读、收藏和离线阅读仍建议实际核对。

## 分发范围

仓库仅发布清单、三个源脚本、说明和校验文件。没有账号、Cookie、GitHub 访问令牌、阅读记录、私人开发记录或漫画图片。后续更改会通过此仓库的提交历史留档。

`SHA256SUMS` 可用于核对文件完整性；它与文件放在同一仓库，不能独立证明发布者身份或替代代码审查。
